Короткий демонстрационный проект с простой системой спавна врагов волнами.
В проекте были использованы следующие плагины:
- Zenject (+ Signals)
- Dotween
- UniTask

Тип врага задается через ScriptableObject-ы в папке Assets\Configs\Enemies (из параметров в этом простом примере только спрайт и внутреннее название)
Настройки волн спавна конфигурируются в файле Assets\Configs\WavesConfig.asset
Настройка волн имеет следующие параметры:
* DelayBefore - задержка перед стартом очередной волны, в секундах
* Enemy - тип врага (определяет спрайт, название)
* EnemyCount - число врагов в волне, спавнятся одновременно, в виде горизонтальной линии
* EnemySpacing - горизонтальный интервал, если EnemyCount указано больше 1
* Position - координаты спавна (если врагов больше 1, то эти координаты используются как центр)
* Target - координаты цели (враг исчезает по их достижению)
* ReachSteps - время, которое потребуется врагу, чтобы достиць целевых координат из исходной точки, в секундах (задает скорость перемещения)
* DelayAfter - задержка после завершения очередной волны, в секундах
* RepeatCount - если больше 0, то повторяет спавн врагов указанное количество раз
* DelayRepeat - если RepeatCount больше 0, то задержка между двумя повторами спавна данной волны (не применяется после финального повтора!)
